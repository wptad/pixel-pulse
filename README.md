# Pixel Pulse ESP32 🎮💡✨

基于 **ESP32-C3 Super Mini** 芯片的高性能原生版，集**线性防御游戏**、**智能台灯**和**艺术灯光秀**于一体的 144 灯珠多功能灯带项目。

> 本项目已从 Arduino 环境迁移至原生 **ESP-IDF 6.0+** 开发环境，基于 C++ 编写，采用 ESP32 原生 RMT 外设驱动，运行更高效、动画更流畅。

---

## 硬件需求

- **ESP32-C3 Super Mini** 开发板
- WS2812B 灯带（144 颗灯珠，高密度）
- 4 个独立按键开关
- 5V 有源蜂鸣器
- 5V 电源（强烈建议给灯带独立供电）

---

## 硬件接线 (ESP32-C3)

得益于 ESP32-C3 灵活的引脚特性，我们完全复刻了与原版 Arduino 一致的逻辑接线方案：

| 组件 | ESP32-C3 引脚 | 说明 |
|------|-------------|------|
| 🟡 黄色按键 | **GPIO 21** | 右侧最顶部 |
| 🔴 红色按键 | **GPIO 20** | 右侧上部 |
| 🔵 蓝色按键 | **GPIO 10** | 右侧中部 |
| 🟢 功能按键 | **GPIO 7**  | 右侧下部 |
| 🔊 有源蜂鸣器 | **GPIO 6**  | 右侧最底部 |
| 💡 WS2812 DIN | **GPIO 5**  | **底部另一侧端点**，独立纯净无干扰 |

> 💡 **注意**：请将 ESP32-C3 与灯带/蜂鸣器的 GND 共地连接。
>
> ⚠️ **调试冲突警告**：本项目使用的 **GPIO 20 与 21** 在 ESP32-C3 上被系统默认用于 **控制台 UART 输出 (USB 调试)**。在插着 USB 线联机调试并运行串口监控 (`idf.py monitor`) 时，按这两个键可能会干扰通讯，导致 PC 端报 `[Errno 6] Device not configured` 串口短暂掉线。这**不影响**离线拔掉 USB 时的正常游玩，但在后续重新设计时强烈建议换成左排的空闲 GPIO（如 0~4）。

## 快速上手

### 1. 环境搭建
确保您已安装 **ESP-IDF** 环境（推荐 5.0 版本以上）。
推荐使用 Visual Studio Code 并安装 **Espressif IDF** 插件。

### 2. 项目依赖
本项目使用了 Espressif 官方的 `led_strip` 托管组件。
编译时，ESP-IDF 会根据 [main/idf_component.yml](file:///Users/tad/workspace/pixel-pulse/main/idf_component.yml) 自动下载该驱动包。

### 3. 编译与烧录
在项目根目录下使用终端执行：
```bash
idf.py build flash monitor
```
或者在 VS Code 中使用底部状态栏：
1. 点击 **Build project** (小圆桶图标)
2. 点击 **Flash device** (闪电图标)
3. 点击 **Monitor device** (小屏幕图标)

## 功能概览

本项目包含 3 种模式循环切换，通过 **长按 GPIO 5 (绿) + 点击 GPIO 4 (蓝)** 进行切换。

- **[游戏模式]**: 拦截红色、黄色、蓝色、绿色的线性防守游戏。
- **[台灯模式]**: 可选 5 种常用光色，支持 10 级亮度记忆调节。
- **[灯光秀模式]**: 包含 10 种数学渲染的高性能全彩灯效动画（彩虹流光、动态火焰、烟花绽放等）。

👉 详细操作说明请参阅：**[USER-MANUAL.md](./USER-MANUAL.md)**

## 架构优势 (迁移亮点)

相比原 Arduino Uno 版本，ESP32 原生版带来了以下优化：
1. **性能突破**：ESP32-C3 160MHz 运行频率（Uno 的 10 倍），动画演算更丝滑。
2. **硬件 RMT 驱动**：不占用 CPU 资源发送灯珠时序，彻底告别闪烁。
3. **原生 C++ 封装**：代码结构采用 C++ 重构，内建 Arduino 兼容 Shim 层，保持原有业务代码风格的同时提升了可扩展性。
4. **FreeRTOS 并发**：引入操作系统任务概念，具备极佳的抗死机稳定性。

## 免责与注意事项

⚠️ **高流供电**：144 颗 WS2812B 满载（白光）电流理论值约 8A。切勿通过 ESP32 芯片引脚取电。务必将 **5V 电源直接供入灯带的 5V 和 GND**。

⚠️ **亮度预警**：固件已做软件限流保护，`MAX_BRIGHT` 默认为 150。
